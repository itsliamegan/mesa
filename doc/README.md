# Mesa Language Documentation

This directory contains documentation for the Mesa programming language and its
implementation. The files in this directory describe:

- [Language](language.md) - The syntax, semantics, core features, and standard
  behavior of the language.
- [Libraries](libraries.md) - The libraries provided by the language.
- [Tooling](tooling.md) - The command-line tooling used to interact with the
  language.
- [Style](style.md) - The style guide for writing Mesa code.
- [Implementation](implementation.md) - The language's current implementation.
  This is the first place to look for information about how the language works
  internally.
